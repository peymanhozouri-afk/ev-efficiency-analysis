# EV Efficiency Analysis

This project analyzes EV trip efficiency using Python, Pandas, and Matplotlib.

## Current Features

- Loads trip data from CSV
- Calculates average Wh/mi
- Compares efficiency at different speeds
- Creates speed vs efficiency graph
- Creates temperature vs efficiency graph

## Early Findings

Trips above 60 mph showed higher Wh/mi than trips at or below 60 mph, meaning energy use increased at higher speeds.

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
