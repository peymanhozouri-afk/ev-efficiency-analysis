# EV Efficiency Analysis

This project analyzes EV trip efficiency using Python, Pandas, and Matplotlib.

## Current Features

- Loads trip data from CSV
- Calculates average Wh/mi
- Compares efficiency at different speeds
- Creates speed vs efficiency graph
- Creates temperature vs efficiency graph

## Early Findings

Trips above 60 mph showed higher Wh/mi than trips at or below 60 mph, meaning energy use increased at higher speeds.

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter 

## Engineering Analysis Features

- City vs highway efficiency comparison
- HVAC energy impact analysis
- Elevation gain analysis
- Efficiency classification system
- Correlation matrix visualization

## Engineering Concepts

This project explores:
- aerodynamic drag
- thermal loads
- elevation energy costs
- operational efficiency
- EV energy consumption trends
